## Экономия (бюджет ограничен — важно)
- Не трать шаги на поиск кнопок по одной: за один вызов браузера выводи СПИСОК всех кнопок/ссылок `main` с текстом и href, потом действуй.
- Не создавай контакты и объекты — они готовы (таблица выше). Сразу к сценарию.
- Не повторяй одну и ту же неудачную попытку больше 2 раз — запиши как находку или «не проверено» и иди дальше.
- Пиши находку в файл СРАЗУ, как нашёл.

## Правила
- Префикс в КАЖДОЙ создаваемой записи: `__smoke__ <ТВОЙ_ID>` (например `__smoke__ A Петров Иван`). Чужие записи не трогать.
- Не удалять/не менять SQL-ом ничего. Только через UI. SQL — только select для проверки.
- Каждую находку подтверждай доказательством (SQL/DOM/лог). Без доказательства — помечай «не подтверждено».
- Пиши отчёт ПО ХОДУ работы (дописывай файл после каждого блока), а не в конце — чтобы при обрыве не потерялось.
  Файл: `/home/ruslan/projects/work-space/housepro-crm/docs/qa/runs/2026-10-28/<ТВОЙ_ID>.md`, формат — §4 плана.
- Экономь вызовы: в одном вызове браузера делай заход+заполнение+сабмит+чтение результата.
  Не печатай весь innerText страниц целиком — режь `.slice(0,1500)` и фильтруй.
- Скриншоты не нужны (модель не видит картинки), работай через DOM.
- Если что-то блокирует (не входит, сервер 500) — запиши как находку и иди дальше по другим пунктам.
