## 2. Задачи (`/tasks`)

- Форма `/tasks/new`: поля «Что сделать» (`title`, обязательное), «Срок» (`datetime-local`), «Приоритет» (low/medium/high), «Описание», плюс поиск и селекты привязки контакт/сделка/объект/договор. Кнопки: «Создать задачу», «Отмена».
- **Пустая отправка**: форма не уходит (URL остаётся `/tasks/new`), но **в DOM нет ни одного сообщения об ошибке** — срабатывает только нативная браузерная валидация (`required`). Инлайн-подсказки у поля нет. Проверено: `errors_on_page()` = только «Выйти»/«*».
- **Создание**: `__smoke__ F Задача Тест`, срок `01.01.2020 10:00` (в прошлом), приоритет «Высокий» → задача создана без каких-либо предупреждений (F-04).
- **Сверка SQL**: `tasks` по орг.: `todo=9 / done=0` → заголовок `/tasks` «9 задач · 8 активных», плашки «ВСЕГО 9 / В РАБОТЕ 8 / ВЫПОЛНЕНО 0 / ПРОСРОЧЕНО 4»; SQL `deadline < now()` → 4. Совпадает.
- **Завершение**: в карточке кнопка «Выполнена» → статус меняется сразу, крошка становится «ЗАДАЧИ / ВЫПОЛНЕНА». После: SQL `done=1, todo=8`; плашки «ВСЕГО 9 / В РАБОТЕ 8 / ВЫПОЛНЕНО 1 / ПРОСРОЧЕНО 3» — совпадает.
- **Фильтры (Реестр)**: «Статус: Выполнено» → 0 строк и понятное «Ничего не найдено» (SQL done=1 до завершения — расхождения нет, т.к. до этого done=0); «Статус: Отменено» → 0 строк (SQL 0); «Статус: К выполнению» → 9 строк (SQL todo=9); «Приоритет: Высокий» → 3 строки (SQL high=3). **Фильтры верны.**
- **Фильтр после F5**: сохраняется, но **НЕ в URL** — состояние лежит в `localStorage` (`tasks:filters`, `tasks:view`, `tasks:search`). Ссылку на отфильтрованный список коллеге не отправить (F-02).
- Канбан лидов: колонки `Новые 2 / Связались 1 / Показ 1 / Подбор 1 / Заинтересованы 3 / Клиенты 2 / Закрыты 0 / Отказ 1` — сумма 11 = SQL по `leads` (new2/contacted1/showing1/searching1/interested3/converted2/rejected1). Совпадает.
- Канбан задач: 4 колонки (К выполнению / В работе / Выполнено / Отменено) — вытащить цифры из DOM не удалось (нет текстовых заголовков-узлов), сверено через плашки.
