# Лиды

Лид — входящее обращение: звонок, заявка с Авито, сообщение в WhatsApp. Это
ещё не клиент и не сделка, а интерес, который надо отработать.

## Когда заводить лид

Заводим **любое обращение**, даже сомнительное. Лид ничего не стоит, а
незаписанное обращение теряется. Если человек уже есть в контактах и пришёл
по новому запросу — всё равно заводим лид: он про конкретный запрос, а не
про человека.

## Как завести

**Лиды → Новый лид.**

| Поле | Комментарий |
|---|---|
| Имя | Как представился |
| Телефон | Основной способ связи |
| Email, Telegram, WhatsApp | Если известны |
| **Источник** | Обязательное: Авито, ЦИАН, Домклик, WhatsApp, Telegram, входящий звонок, сайт, рекомендация, Instagram, VK, другое |
| Ответственный | Кто ведёт. По умолчанию — вы |
| Следующий контакт | Дата и время, когда перезвонить |
| Тип сделки | Аренда, продажа, управление, коммерция, субаренда |
| Тип объекта, комнаты, район | Что ищет |
| Бюджет от/до, площадь от/до | Рамки поиска |
| Комментарий | Всё, что сказал клиент своими словами |

Источник заполняем честно — по нему потом видно, какая площадка окупается.

## Воронка: восемь статусов

Порядок на доске слева направо:

| Статус | Что означает |
|---|---|
| Новый | Обращение поступило, ещё не связывались |
| Связались | Дозвонились, запрос уточнён |
| Показ | Показ назначен или проведён |
| Подбор | Подбираем варианты |
| Заинтересован | Клиенту что-то понравилось |
| Конвертирован | Стал клиентом, создана сделка |
| Закрыт | Работа окончена без сделки |
| Отказ | Клиент отказался |

Статус меняется перетаскиванием карточки на доске или в карточке лида.
«Заинтересован» проставляется **сам**, когда по показу отмечен результат
«Заинтересован».

«Конвертирован», «Закрыт» и «Отказ» — конечные: из них лид дальше не двигают.

## Как вести

- Работать с доски: колонки показывают, где лид застрял.
- В карточке — история активностей: звонки, встречи, заметки. Записывать
  каждое касание, чтобы коллега мог подхватить.
- Поле «Следующий контакт» — обещание перезвонить. Не оставлять пустым у
  живого лида.
- Телефон в списке кликается: звонок и WhatsApp с одного нажатия.

## Конвертация в клиента

Когда клиент готов работать — в карточке кнопка конвертации. Система создаёт
**контакт** с ролью «Клиент» и статусом «Новый», переносит имя, телефон, email,
Telegram, WhatsApp, источник и комментарий, переводит лид в «Конвертирован» и
открывает карточку нового контакта. Дальше работа идёт в сделке, лид остаётся
в истории.

Не конвертируем «на всякий случай»: контакт без сделки только засоряет базу.

## Групповые действия

Выделить строки в реестре и разом сменить статус, назначить ответственного
или удалить. Удобно, когда с площадки пришла пачка нерелевантных заявок.

## Куда лид связан дальше

- Из лида создаётся **подборка** объектов с публичной ссылкой.
- На лида назначается **показ**.
- После конвертации появляется **контакт**, а затем **сделка**.
