# Подборки

Подборка — набор объектов под конкретного клиента, который открывается по
ссылке без входа в CRM. Заменяет пересылку фотографий в мессенджере.

## Как собрать

**Подборки → Новая подборка:** название и клиент (лид), затем в карточке
добавляются объекты из базы.

Название клиент увидит — стоит писать по-человечески: «Двушки до 40 тысяч,
Взлётка», а не «Подборка 3».

## Публичная ссылка

У каждой подборки свой адрес вида `/c/<токен>`. Ссылку можно отправить в
мессенджере или письмом прямо из карточки.

Переключатель **«Публичная / Приватная»** управляет доступом: приватную по
ссылке не открыть. Пока подборка собирается — держим приватной.

Клиент видит объекты с фото, ценами и описанием, без внутренних данных
агентства.

## Как вести

- Реестр показывает клиента, число объектов, доступ и дату создания.
- Фильтр по доступу отделяет опубликованные от черновиков.
- Устаревшие подборки удаляются группой — ссылка перестаёт работать.

## Связи

Подборка привязана к лиду: из карточки лида видно, что ему отправляли.
Объекты берутся из общей базы — цена и фото в подборке всегда актуальные.
