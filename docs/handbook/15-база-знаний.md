# База знаний

Инструкции агентства прямо в системе: как принимать заявки, как готовить
договор, что делать с объектом в управлении. Сотрудник читает там же, где
работает, — не в мессенджере и не в чужом облаке.

## Как устроено

Статьи собраны по рубрикам: Общее, Продажи, База объектов, Документы, Деньги,
Администрирование. Рубрику можно завести свою — поле свободное.

Сверху — поиск по заголовкам и описаниям и фильтр по рубрике.

## Кто может писать

| Роль | Что может |
|---|---|
| Администратор | Читать, писать, править, удалять |
| Менеджер | Читать, писать, править |
| Риелтор | Только читать |
| Бухгалтер | Только читать |

## Как написать статью

**База знаний → Новая статья.**

| Поле | Комментарий |
|---|---|
| Заголовок | По нему строится адрес статьи |
| Рубрика | Из списка или своя |
| Порядок | Чем меньше число, тем выше в рубрике |
| Опубликована | Снятая галочка = черновик, сотрудники его не видят |
| Краткое описание | Одна строка, видна в списке |
| Текст | Разметка markdown |

## Разметка

| Что нужно | Как написать |
|---|---|
| Заголовок раздела | `## Заголовок` |
| Подзаголовок | `### Подзаголовок` |
| Список | строки, начинающиеся с `-` |
| Нумерованный список | `1.`, `2.`, … |
| Жирный | `**важное**` |
| Код или название поля | `` `поле` `` |
| Ссылка | `[текст](адрес)` |
| Таблица | строки через `|`, вторая строка из дефисов |

Вкладка **«Просмотр»** показывает статью так, как её увидит сотрудник, — до
сохранения.

## Черновики

Пока статья не готова, снимайте галочку «Опубликована»: в списке она будет
помечена как черновик и видна только тем, кто может править.

## Что здесь держать

Хорошо заходят: порядок действий в спорных ситуациях, чек-листы приёма
объекта, правила общения с клиентом, шаблоны сообщений, разбор частых ошибок.

Не стоит: сведения, которые меняются каждую неделю (цены, остатки) — для них
есть сами разделы CRM.
