# Телеграм-бот

Бот агентства — быстрый доступ к CRM с телефона, без входа в браузер.

## Главное меню

| Раздел | Что делает |
|---|---|
| CRM | Лиды, сделки, оплаты, задачи |
| Канал | Публикации в телеграм-канале агентства |
| Мультиагент | Исследование рынка по запросу |
| Настройки | Автопостинг и доступ к боту |
| Помощь | Подсказки по работе |

## CRM из телефона

Через бота смотрят и заводят лидов и сделки, отмечают оплаты и ведут задачи.
Удобно на выезде: после показа можно сразу записать результат, не открывая
ноутбук.

Голосовые сообщения бот расшифровывает — заметку можно наговорить.

## Канал

Бот готовит и публикует посты в канал агентства: разовый пост, кейс из
практики, расписание публикаций и рубрики. Есть статистика по постам и
переходам.

Автопостинг ставится на паузу и возобновляется в настройках бота.

## Доступ

Бот работает только с разрешёнными пользователями — список ведётся в
настройках бота, добавляет администратор. Посторонний, написавший боту,
данных не получит.

## Уведомления

В общий чат агентства бот присылает новые лиды — сразу после появления заявки.
