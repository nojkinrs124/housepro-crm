# Объекты

База недвижимости агентства: квартиры, дома, коммерция, офисы, склады,
участки. Один объект — одна карточка, сколько бы сделок по нему ни прошло.

## Как завести

**Объекты → Добавить объект.**

| Блок | Поля |
|---|---|
| Основное | Название, адрес (с подсказками и координатами), тип объекта, тип сделки, собственник |
| Площади | Общая, жилая, кухня, комнаты, этаж и этажность, высота потолков |
| Дом | Тип дома, материал стен, год постройки, лифт, парковка |
| Коммуникации | Отопление, водоснабжение, интернет, ТВ |
| Право | Основание собственности, кадастровый номер, площадь участка, обременения |
| Деньги | Цена, залог, вознаграждение за управление |
| Описание | Текст для площадок |

Адрес вводится через подсказки — вместе с ним сохраняются координаты и метро,
они нужны для выгрузки на Яндекс и Домклик.

**Тип сделки «Управление»** переводит объект в раздел
[Управление](08-управление.md).

## Статусы

| Статус | Когда ставить |
|---|---|
| Свободен | Готов к показам и выгрузке на площадки |
| Забронирован | Есть договорённость, но договора ещё нет |
| Сдан | Действует договор аренды |
| Продан | Сделка купли-продажи закрыта |
| Неактивен | Временно снят с продажи |

На площадки выгружаются только объекты в статусе **«Свободен»**.

## Фото

В карточке — менеджер фотографий: загрузка, порядок, удаление. Первое фото
идёт обложкой в списках и на площадках. Без фото объявление на площадке
работает плохо.

## Публикация

Два независимых переключателя прямо в списке и в карточке:

- **Авито** — объект попадает в XML-фид для автозагрузки;
- **Сайт** — объект показывается на публичном сайте агентства.

Выгрузка требует заполненных названия, адреса, цены и описания, а статус
должен быть «Свободен». Ссылки на фиды — в
[настройках экспорта](13-настройки.md).

## Счётчики

В карточке объекта — блок счётчиков: электричество, холодная и горячая вода,
газ, отопление. У каждого серийный номер, единица измерения и тариф. Показания
вносятся с датой, система считает расход и сумму.

Нужны в первую очередь объектам в управлении — по ним готовится отчёт
собственнику.

## Как вести

- Два вида: карточки с фото и плотный реестр. Реестр удобнее, когда объектов
  много: видно тип, сделку, параметры, статус и цену сразу.
- Фильтры: статус, тип сделки, тип объекта, публикация на Авито.
- В карточке — договоры и сделки по объекту, файлы и документы.

## Собственник

Указывается в форме объекта — при создании или позже, в редактировании. Если
собственника в базе ещё нет, кнопка «Создать» рядом с полем заводит контакт
на два поля (имя и телефон) не выходя из формы объекта; остальное —
паспорт, реквизиты — дозаполняется потом в его карточке.

Без собственника объект работает, но в разделе «Управление» и в отчёте на его
месте будет прочерк, а договор подписывать не с кем. Карточка объекта
показывает это прямо: блок «Собственник» с пометкой «Не указан».

## Чего не хватает

Наверху карточки система перечисляет, что из-за пустых полей молча не
сработает:

| Пусто | Что не работает |
|---|---|
| Собственник | Объект не попадёт в отчёт собственнику, подписывать некем |
| Координаты адреса | Объект не уйдёт на Яндекс и Домклик, не встанет на карту — вводите адрес через подсказку |
| Описание, цена | Объявление не выгрузится на площадки |
| Вознаграждение (у объектов в управлении) | В отчёте вознаграждение агентства посчитается нулём |

Отдельно система следит за расхождением статуса и договора: если по объекту
есть действующий договор аренды, а статус остался «Доступно», сданный объект
продолжит выгружаться в рекламу как свободный. И наоборот — статус «Сдано»
без договора аренды означает, что арендатор не появится в «Управлении», а
начисления по аренде не создадутся.

## Связи

Объект связан с собственником (контакт), сделками, договорами, показами,
подборками, платежами и задачами. Из карточки видно всё это разом.
