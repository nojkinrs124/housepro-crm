# Сделки

Сделка — работа по конкретному клиенту и объекту: от первого интереса до
денег. В ней сходятся стороны, объект, договоры и платежи.

## Когда заводить сделку

Когда клиент определился с намерением: выбрал объект или готов смотреть
конкретные варианты. До этого достаточно лида.

## Как завести

**Сделки → Новая сделка.**

| Блок | Поля |
|---|---|
| Тип | Аренда, продажа, управление, коммерция, субаренда |
| Этап | Стартует с «Новая» |
| Стороны | Собственник и клиент — выбираются из контактов, у юрлиц можно указать представителя |
| Объект | Из базы объектов |
| Финансы | Сумма сделки, комиссия агентства, аванс, первый взнос, сумма торга |
| Оплата | Способ оплаты, банк, дата одобрения — для ипотеки |
| Сроки | Ожидаемая дата закрытия |
| Источник, примечания | Откуда пришла и что важно помнить |

Сумма и комиссия нужны аналитике: по ним считается объём и заработок.

## Этапы воронки

`Новая → Показ → Переговоры → Договор → Оплата → Завершена`

Отдельно стоит **Отменена** — она вне последовательности.

Этап меняется перетаскиванием на доске или в карточке сделки.

## Что двигается само

Система продвигает сделку вперёд по ходу работы:

- создан договор по сделке → этап **Договор**;
- сформирован DOCX договора → этап **Оплата**;
- отмечен полученный платёж → этап **Завершена**.

Автоматика работает **только вперёд** и никогда не трогает сделки в статусах
«Завершена» и «Отменена» — то, что закрыто руками, остаётся закрытым.

## Как вести

- В карточке — комментарии команды: обсуждение по сделке хранится рядом с ней,
  а не в переписке.
- Блок «Документы»: договоры по сделке и приложенные файлы.
- Блок «Задачи»: что нужно сделать по этой сделке, с дедлайнами.
- Лента общения: звонки, WhatsApp, письма и заметки по клиенту.
- Степпер сверху показывает, где сделка сейчас.

## Связи

- **Контакты** — стороны сделки. Из карточки контакта видно все его сделки.
- **Объект** — из карточки объекта видно сделки по нему.
- **Договор** — создаётся из сделки, стороны и объект подставляются сами.
- **Платежи** — привязываются к договору сделки и попадают в бухгалтерию.
