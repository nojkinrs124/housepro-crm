# Бухгалтерия

Все деньги агентства: поступления от клиентов, расходы, плановые начисления и
факт оплаты.

## Операция

Основная единица — **операция**: доход или расход. Платёж по договору —
это тоже операция, только заведённая с карточки договора.

**Бухгалтерия → Новая операция.** На виду:

| Поле | Комментарий |
|---|---|
| Тип | Доход или расход |
| Сумма | |
| Дата | Когда прошла |
| Описание | Текстом, что за платёж |
| Категория | Из справочника категорий |

В свёрнутом блоке **«Дополнительно»** (раскрыт, если операция заведена с
объекта или договора):

| Поле | Комментарий |
|---|---|
| Статус | Запланировано, выполнено, отменено |
| Способ оплаты | Наличные, счёт, карта |
| Срок оплаты | Для плановых начислений |
| **Объект** | По нему считается доходность объекта в управлении |
| Договор, сделка, контакт, сотрудник | Привязки |

Если объект не выбран, он подставится из договора. Расходы **без договора** —
коммуналка, ремонт — объект нужно выбрать руками, иначе они не попадут в
доходность объекта.

## Статусы и что они значат

- **Запланировано** — начисление выставлено, денег ещё нет. По таким система
  напоминает клиенту о сроке и о просрочке.
- **Выполнено** — деньги получены или потрачены. Только такие идут в отчёты и
  в прибыль. Запланированная операция проводится кнопкой **«Провести»** в
  карточке — дата проведения запишется сама.
- **Отменено** — начисление снято.

## Касса и доход агентства — две разные цифры

На странице два ряда цифр за месяц, и они специально не совпадают:

- **Приход / Расход / Сальдо** — вся касса: любые деньги, прошедшие через
  агентство, включая аренду клиентов и депозиты — их агентство только
  передаёт собственнику, себе не оставляет.
- **Доход / Расход / Прибыль агентства** — то же самое без транзита: сколько
  агентство заработало и потратило на самом деле. Строка **«Транзит за
  месяц»** — это и есть разница между кассой и доходом агентства.

Это те же цифры, что и «Доход агентства» в Аналитике за тот же период — если
не совпадают, значит выбран разный период, а не по-разному посчитано.

## Срез по направлению, сотруднику и объекту

Строка фильтров под заголовком режет сразу всё на странице — обе строки цифр,
графики и список операций внизу: выбрали «Управление» — и касса, и доход
агентства, и список показывают только операции по обслуживанию. Фильтры живут
в ссылке (можно скопировать и отправить коллеге с уже готовым срезом) и не
пересекаются с поиском/статусом в самом списке операций — те сужают уже
отфильтрованное.

Направление у операции без договора или обслуживания не определить — такие
операции (например, комиссия по сделке без указанного договора) не попадут ни
в один срез по направлению, но останутся видны при сбросе фильтра.

## Категории

**Бухгалтерия → меню «…» → Категории** — справочник доходов и расходов с цветом.
Базовый набор есть у каждой организации с первого дня: «Комиссия агентства»,
«Арендный платёж», «Управление объектом», «Депозит», «Выплата собственнику»,
«Коммунальные услуги», ремонт, клининг и прочие. Системные категории не
удаляются — по ним считается взаиморасчёт с собственником в управлении и
доход агентства в аналитике; свои категории добавляются рядом.

## График начислений

В карточке договора (и в карточке объекта в управлении) договор разворачивается
в помесячные начисления на весь срок: с залогом первой строкой, с выбранной
периодичностью и ежегодной индексацией.

Пересоздание графика **не трогает оплаченные строки** и ручные платежи.

## Повторяющиеся операции

**Бухгалтерия → меню «…» → Периодические** — правила для регулярных платежей: аренда
офиса, зарплата, подписки. Указываются сумма, периодичность, день месяца и
срок действия. Раз в сутки система создаёт операции по этим правилам.

## Счёт на оплату и ссылка на оплату

- **Счёт** — печатная форма с реквизитами агентства и суммой прописью,
  открывается из строки платежа.
- **Ссылка на оплату** — клиент платит картой онлайн; создаётся кнопкой в
  строке начисления, если подключён приём платежей.

## Сверка с банком

**Бухгалтерия → меню «…» → Сверка с банком** — загрузка выписки из 1С. Система разбирает
файл, сопоставляет платежи с начислениями и предлагает отметить оплаченные.
Файл не в формате 1С будет отклонён.

## Напоминания

Ежедневно утром система рассылает письма по плановым начислениям:

- за 3 дня до срока — напоминание;
- после срока — уведомление о просрочке, не чаще раза в неделю.

Письмо уходит на email клиента из договора. Нет email — нет письма. По
отменённым договорам напоминания не идут.
