## Как этим пользоваться

**Новому сотруднику.** Прочитать [обзор](00-обзор.md), затем файлы по своим
разделам. Риелтору хватит 01–06, бухгалтеру — 07, 08, 10.

**Для NotebookLM.** Загрузить файлы папки как отдельные источники — по одному
на раздел. Так ответы получаются точнее, чем от одного длинного документа, и
в ответе видно, из какого раздела взято. Для видео-обзора порядок глав в
оглавлении выше уже подходит как сценарий: обзор → путь клиента (лиды →
сделки → показы → договоры) → деньги → управление → администрирование.

**При изменениях в системе.** Правится тот файл, чей раздел изменился, тем же
коммитом, что и сама доработка. Если инструкция расходится с интерфейсом —
верить интерфейсу и чинить инструкцию.

## Что не входит

Технические правила разработки — в `CLAUDE.md` и `docs/` рядом:
как устроен код, миграции, дизайн-система, план работ. Этот справочник —
только про работу в интерфейсе.
