## Что сделано иначе, чем в ТЗ (по коду, а не по памяти)

- Дизайн-система: в ТЗ упомянуты Unbounded + Inter и зелёная палитра — в репозитории
  публичный сайт живёт на токенах `var(--hp-*)` («Кабинет», Source Sans 3 + Source
  Serif 4). Сделано по коду.
- Форма: в ТЗ — «по канону ServerActionForm». Существующий путь создания лида с сайта —
  Route Handler `/api/public/leads` (service-role, honeypot, rate limit по IP, Telegram).
  Его и расширили (`source`, `page`, `context`); второго пути не появилось.
- Контекст лида: колонки jsonb в `leads` не было — добавлена `leads.metadata jsonb`
  (миграция `supabase/migrations/20260914_leads_metadata_jsonb.sql`). Плюс заполняются
  `district`, `rooms`, `budget_min`, `deal_type` — их уже показывают доска и карточка лида.
  Суммы калькулятора на сервере пересчитываются из ставки, а не берутся из запроса.
