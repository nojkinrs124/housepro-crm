- **Контур:** внутренний, живых клиентов нет, единственный пользователь — Руслан.
- **Команда:** Руслан + Claude, надолго. Поэтому здесь **нет** CODEOWNERS, PR-темплейтов, branch protection, husky/lint-staged — это процесс под команду, которой не существует. Не предлагать их снова, пока команда реально не вырастет.
- **Приоритет сейчас:** техдолг из аудита 20.07.2026, в фиксированном порядке (см. ниже), затем — фичи (Telegram-бот, публичный API, Stripe live keys).
- **Философия тестов:** не покрытие, а регресс-защита. Не гнаться за метрикой — важно, чтобы новая фича не тихо ломала старую.

- [ ] Если задача похожа на новую фичу/значимое решение — прогнать через `grill-me`, а не додумывать самому.

## Во время разработки

- [ ] Новая форма → только через `ServerActionForm`, без `formAction()`-антипаттерна.
- [ ] Новый Server Component → ноль event handlers, ноль `useState`/`useEffect`.
- [ ] Новый Supabase-клиент в API route → через `getSupabaseAdmin()` лениво внутри хендлера, с `no-store` fetch-конфигом. Не копировать инстанциацию в 23-й файл — если паттерн повторяется в очередной раз, вынести в общий `withOrgAuth()`/`withApiKeyAuth()`.
- [ ] Новый GET route с данными по org → обязательно `export const dynamic = 'force-dynamic'`.
- [ ] Новая RLS-политика → без сабквери к той же таблице (используй `get_user_org_id()`), обёрнута в `DO $$ BEGIN IF NOT EXISTS ... END $$`.
- [ ] Правишь файл >300 строк — выносишь логику в `features/*/services`, не оставляешь как есть «раз уж всё равно тут».
- [ ] Если меняешь денежный/юридический поток (payments, contracts, billing) — обязательно тест на этот поток, даже если остальное без тестов.

## Перед пушем (обязательно, без исключений)

- [ ] `npm run check` зелёный (tsc → event handlers → client/server boundary → build → test).
- [ ] `.env.local` с плейсхолдерами удалён перед коммитом, если создавался только для проверки.
- [ ] Если менялась схема БД — файл миграции закоммичен вместе с кодом, не отдельно потом.
- [ ] Коммит + push через PAT-in-URL паттерн, сразу после push — сброс на чистый HTTPS `origin` (токен не должен оставаться в `git remote -v`).

## Красные флаги — остановиться и спросить, а не додумывать

- Память (`userMemories`) утверждает одно, а код в репозитории — другое → **доверять коду**, разошедшееся зафиксировать и сообщить.
