# SEO и индексация HousePro

## When to Use

- Работа с индексацией: robots, sitemap, IndexNow, GSC, Яндекс.Вебмастер.
- Подбор и проверка ключевых слов, тексты под поиск.
- Нужно понять, почему страница не в индексе.


Два независимых домена, не смешивать:

- **Техническая индексация** — canonical, sitemap, robots, редиректы, подтверждение
  домена, IndexNow, Search Console / Яндекс.Вебмастер, Метрика и GA4 через API.
  Процедура и подводные камни — `references/seo-indexing.md`.
- **Содержание и ключевые слова** — какие запросы и куда писать, что брать из
  структурированных полей БД, чего не обещать. — `references/seo-keyword-audit.md`.

## Что проверять первым

1. `getent ahosts housepro24.ru` + запрос страницы: прод может смотреть не туда,
   куда кажется (домен куплен, но DNS на парковке регистратора, сайт живёт на
   `*.vercel.app`). Прежде чем обещать владельцу «после слияния появится на домене» —
   проверить фактически.
2. Технические адреса `*.vercel.app` должны отдавать 308 на канонический домен;
   canonical и sitemap — на `https://housepro24.ru`.
3. Новый контент — уведомить IndexNow (иначе страница ждёт обхода неделями).
4. Env в Vercel без редеплоя не применяется; локальный DNS-кэш врёт.

## Ключевые слова

- Сверять гипотезы с реальными данными в БД (районы, типы объектов, цены), а не
  придумывать список: «ключевые слова из структурированных полей» — не поэзия.
- SEO-title и meta собираются из данных объекта/услуги, а не пишутся руками в
  разметку страницы.
- FAQPage — из уже существующего UI (реальные вопросы с экрана), не отдельным
  списком «для поисковика».
- Тексты — по правилам брендбука: от «я», «от 10%» за управление, без обещаний
  гарантии платежа вне тарифа «Премиум».
- Что не делать и что сильнее любых правок в коде — в
  `references/seo-keyword-audit.md` (разделы «Что не делать» и «Что сильнее любых
  правок»).

## Доступ к кабинетам без пароля владельца

Search Console и Яндекс.Вебмастер доступны через OAuth-приложение один раз, дальше
— по API без ручного входа. Полный рецепт (создание проекта, подтверждение
владения, запрос индексации) — `references/seo-indexing.md`, раздел «Полный доступ
к Search Console и Яндекс.Вебмастеру через API».

## Границы

- Контент сайта живёт в `src/features/site/` (`config.ts`, `uslugi/config.ts`) —
  тексты и числа править там, не в разметке.
- Тарифы: источник истины — `src/features/site/uslugi/config.ts`. Сейчас: подбор
  нанимателя 25%, управление от 10%, «Премиум» 15%, сопровождение продажи/покупки
  **2% + 30 000 ₽**. Брендбук должен совпадать с кодом; расхождение — баг документа.
- Проверка после правок — `npm run check` (страницы сайта тоже проходят
  визуальный стандарт).
